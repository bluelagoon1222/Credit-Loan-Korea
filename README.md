# Credit-Loan-Korea · 신용·대차 CHECK

국내 전 종목의 대차 잔고·공매도 잔고 증가/감소 상위를 좌우로 비교하는 사이트입니다.
(신용융자 종목별 순위는 준비 중)

- 대차 잔고: 공공데이터포털 '금융위원회_주식대차거래정보' (getStckLnbDetail)
- 공매도 잔고·주가·상장주식수: KRX 정보데이터시스템 (pykrx, KRX 회원 로그인)
- 갱신: 평일 19:00, 07:20 (GitHub Actions)

## GitHub Secrets
| 이름 | 값 |
|---|---|
| KRX_ID | KRX 정보데이터시스템 아이디 (사모펀드 수급 CHECK와 동일) |
| KRX_PW | KRX 비밀번호 |
| DATA_GO_KR_KEY | 공공데이터포털 일반 인증키 (Decoding) |

## 지표
- 상장주식 대비(%) = 잔고 수량 / 상장주식수
- 변화율(%) = 기간(1·5·20·60거래일) 잔고 수량 증감률
- 비율 변화(%p) = 상장주식 대비 비율의 증감
- 증감 금액 = 증감 수량 × 현재 종가 (추정)
